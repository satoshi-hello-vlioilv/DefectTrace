# DefectTrace v4.0（検査計画像ビュワー）

検査計（LS3・LS4・DL2・NS1・TLV）のロットを、欠陥の画像・MAP・転写候補・ピッチ候補・ロット情報で見るアプリ。

## 使い方

1. 配られた `DefectTrace.exe`（共有フォルダの置き場・配る入口）を開く。この PC へ写り、以後はデスクトップ・スタートのショートカットから開く
   （初めての PC では「ショートカットを作りますか」と尋ねます）
2. 左の木で 設備 → 年 → 年月 → 日 → ロット を選ぶ。開いた瞬間に全部の画像の枠が並び、縮小画像は画面の頭から順にできていく
3. 新しい版が配られると、使っている間に裏で取り込み、画面の右上で「開き直して更新」を知らせます（次に開いたときにも入れ替わります）

Python・Flask・ブラウザは要りません（版 3.8 までの run.bat は無くなりました）。Windows 11 には要る部品（WebView2）が入っています。

設定は `%LOCALAPPDATA%\DefectTrace\config.json`（設備の場所・更新の置き場など。初めて開いたときに既定を写して作る）。
版 3.8 の `config.json`・`pins.json` を同じ場所へ写せば、そのまま使えます。

- 作り: `program/docs/DESKTOP.md`
- 配り方と更新: `program/docs/DISTRIBUTION.md`
- 検査データの形: `program/docs/DATA_FORMAT.md`
- 開発の決まり: `CLAUDE.md`

## v4.0 の変更

- exe から起動するデスクトップ版（中身は Rust・画面はこれまでと同じ HTML）。Python・Flask なしで動き、ポートも開かない
- 画像の読み込みを速く（7 案を測って決めた）: 開いた瞬間に名前と数・縮小画像は画面の頭から芯の数だけ並べて・CAB は exe の中で展開・
  作業場所には縮小画像だけ（書く量は約 1/20）・原寸はメモリで伸ばして最近の CAB を覚える
- 配る版の作り方・配る置き場・裏での更新と入れ替え・開けない版は前の版に戻す（LotScope と同じ仕組み）
- COND*.xml が wavedata/cond の下だけにあるロットでも分類名を読む

## これまでの変更

### v3.4 の変更
1. MAP：記号の大きさをスライダーで調整（ブラウザに保存）
2. ピッチ：同一面・同一幅位置（±幅差）で、間隔がそろう（±ピッチ差）欠陥列を抽出
   - 条件：幅差（初期 ±5mm）、ピッチ差（初期 ±0.03m）、最小ピッチ数（初期 3 = 欠陥4個以上）、
     ピッチ範囲（初期 0.1m 以上）、欠け許容（途中の未検出をピッチの2〜4倍間隔で許容）
   - 一覧：面、ピッチ、個数、平均幅位置、長さ範囲、ばらつき、推定ロール径（ピッチ÷π）
     欠陥を並べ、間の矢印に実際の間隔を表示
   - クリックでMAPに列を表示、ダブルクリック/Enterで拡大、←→で列内、↑↓で候補切替、CSV出力
3. データ解析の修正・追加
   - DateTime の Kind（UTC保存）を判定してPCの現地時刻に変換（STAT_INFO などが9時間ずれていた）
   - カメラ番号を「面 カメラn（視野範囲mm）」で表示（cond/SystemCond.xml）
   - 検査幅(mm) = INSP_INFO の検査範囲終点−始点（サマリに追加）
   - ロット情報に分類別集計（INSP_INFO.classification_count と面別件数）
   - 転写候補：SystemCond.xml の表裏スキャン方向を表示（反転要否の目安）
   - 画像情報にライン速度を追加
4. 転写候補の表示レイアウト修正（候補カードの横伸び・基準カードの縦伸びを解消）

### データの読み方（検証済み：LS3 2026_10_25_22_03_53、2026_10_23_21_27_46）
- .dat : [ヘッダ長][版番号][1件のバイト数][名前長+名前] の後、[1byte + 1件分] の繰り返し
- 画像 N.bmp → IMAGE_LINK(image_fileno=N) → DETECT_INFO[detect_recno]
- 幅方向OS～(mm) = x_mm − base_x ／ 長さ方向(m) = y_mm ÷ 1000 ／ 面積 = area_mm
- 分類 = cond/COND*.xml classification_conditions[kindID]、面 = cond/Common.xml group_conditions[group]
- DETECT_INFO.camera は全体通し番号（裏面 0〜5、表面 6〜11 など。SystemCond.xml の順）

## v3.5 の変更
- アプリ名を DefectTrace に変更（画面左上・タブ名・run.bat のウィンドウ名）
- 表示切替ボタン：画像一覧／転写候補／ピッチ候補
- ツリー：段差（字下げ）を縮小し、ロット行に表示できる幅を拡大
- ロット一覧の時刻を表示項目化（並べ替え・削除・書式切替 hh:mm ⇔ hh:mm:ss）
  既存の pins.json にはロットNoの次に「時刻（hh:mm）」が1回だけ自動追加される
  データ項目「ロット：フォルダ名（作業日時）」から作業時刻・作業日を追加できる
- ロット一覧の表示項目エリア：通常は折りたたみ。ドラッグ中は自動で表示、［項目▾］で常時表示

### v3.6 の変更（設備ごとのフォルダ構成の違いに対応）
- 画像の置き方を画像フォルダ（img / fm_img など）ごとに自動判定
  - CAB（img/0000.cab …）：従来どおりローカルキャッシュへ展開（LS3・LS4・TLV）
  - サブフォルダ（img/0000/*.bmp）：展開せず共有フォルダから直接表示（DL2）
  - 直下の画像（img/*.bmp）：同上
  - サムネイルは常にローカルキャッシュに作成（共有フォルダには書き込まない）
- 画像の無いロットは「画像がありません」と表示し、欠陥データ（MAP・転写/ピッチ候補・ロット情報）は表示
- 面の表／裏はロットごとに Common.xml の表示名で判定（DL2 は group0=表面・group1=裏面で LS3 と逆）
- 分類名・マーク・色はロットごとの COND*.xml から取得（DL2：表濃・表淡・裏濃・裏淡・表周期・裏周期 など）
- DETECT_INFO の type≠1 のレコード（欠陥以外の記録）は MAP・集計・候補抽出から除外
- cond フォルダに COND*.xml / Common.xml が無い場合は、ロット内の他の場所（wavedata/cond など）から取得
- INSP_INFO.DAT など拡張子の大文字小文字の違いに対応

### v3.7 の変更
- 日時の読み方を修正：DateTime の保存方式（UTC保存／現地時刻保存）をファイルごとに自動判定
  （フォルダ名の時刻に近い方を採用。時差は config.json の utc_offset_hours＝9）
- ロット情報に「日時の整合」：フォルダ名と 検査開始・終了／最初・最後の欠陥／統計 の時刻差を表示（差が大きい行は黄色）
- 多量チェック：分類名に「多量」を含む分類の件数をロットごとに集計
  - ロット一覧：多量ありは赤バッジ「多量 n」、0件は ✓、日付行に多量ありのロット数
  - 絞込欄に「多量」と入力すると多量ありのロットだけ表示
  - ロット情報「検査状態チェック」に件数と面別内訳（INSP_INFO 集計と DETECT_INFO 実数が違う場合は併記）
  - 対象の分類名は config.json の overload_names で変更可
- 時刻の不一致があるロットは一覧に ⏱ を表示（しきい値 time_warn_minutes＝10分）

### v3.8 の変更（LS3 2026_10_24_19_42_05 の実データで検証）
- 多量の判定方法を実データに合わせて変更
  - 件数：INSP_INFO.error_count（定義ファイルの説明「多量集計数」）
  - 内訳：DETECT_INFO の type=2・kindID=1100 のレコード（397件 = error_count と一致）
  - COND*.xml の分類には「多量」は無いため、分類名による判定は予備として残す
  - 対象の type / kindID は config.json の overload_types / overload_kind_ids で変更可
- ロット情報「検査状態チェック」：多量の件数・面別・欠陥数の内訳（合計＝通常＋多量）・発生位置・カメラ別、
  欠陥数上限（INSP_INFO.detect_max_status：1=最大数オーバー、2=HDD容量オーバー）
- ロット一覧：多量バッジに加え、欠陥数上限オーバーを「上限」「HDD」バッジで表示
- MAP：多量の範囲（幅×長さ）を赤い帯で表示
- 日時の整合：統計 最後・スリット設定時刻・日付フォルダの一致を追加。欠陥・統計の時刻が検査開始〜終了の範囲外なら警告
- 画像フォルダが無いロットで MAP・転写候補・ピッチ候補が表示されなかった不具合を修正
